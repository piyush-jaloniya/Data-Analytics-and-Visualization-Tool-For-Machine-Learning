# Data-Analytics-and-Visualization-Tool-For-Machine-Learning

Overview

A comprehensive desktop application built with Python and Tkinter that provides an intuitive interface for machine learning data analysis, model training, and visualization. This tool simplifies the ML workflow by combining data loading, preprocessing, model training, prediction, and visualization in a single user-friendly application.

Key Features

Data Loading: Supports CSV and Excel files with automatic preview

Model Training: Multiple ML algorithms including:

Linear/Multiple Regression

Logistic Regression

Decision Trees

Random Forest

SVM

Naive Bayes


Interactive Visualization: Generate various plots including:

Scatter plots

Confusion matrices


Real-time Predictions: Manual input fields for making predictions with trained models


Modern UI: Clean, responsive interface with ttkbootstrap themes


Performance Metrics: Automatic accuracy calculation for model evaluation

Python 3.6+

pandas
